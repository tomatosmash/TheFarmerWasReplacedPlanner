# 浇水系统

## 含水量

- 地块含水量范围：**0 ~ 1**
- `get_water()` 返回无人机下方向地块的当前含水量

### 生长速度加成
- 生长速度随含水量**线性增长**：

| 含水量 | 生长速度倍率 |
|--------|------------|
| 0 | 1× |
| 0.25 | 2× |
| 0.5 | 3× |
| 0.75 | 4× |
| 1 | 5× |

> 满水时植物生长速度为 **5 倍**！

## 蒸发机制

- 地块随时间**逐渐变干**
- 每秒平均失去当前含水量的 **1%**（有随机波动）
- 维持高含水量比维持低含水量**消耗更多水**（因为蒸发量和当前含水量成正比）

## 浇水操作

### 水源获取
- 每 **10 秒**自动获得 **1 罐水**
- 升级 `Unlocks.Watering` 后每 10 秒获得的水量**翻倍**

### 浇水
```python
use_item(Items.Water)
```
- 对无人机**下方地块**浇水
- **1 罐水 = 0.25 含水量**
