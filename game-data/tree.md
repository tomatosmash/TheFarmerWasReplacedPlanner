# 树 (Tree)

## 基本信息
- 实体名称：`Entities.Tree`
- 每棵树产出 **5 份木材**（比灌木效率更高）
- 可种植在**草地**或**耕过的土地**上（与灌木相同）

## 生长速度与间距

树喜欢保持空间——相邻的树会互相减速：

- 每在**正北、正东、正西、正南**（4 个相邻方向）有一个相邻的树，生长时间**翻倍**
- 包含斜对角不影响，只计算 4 个相邻方向

### 密度与生长时间

| 相邻树数量 | 生长倍率 |
|------------|----------|
| 0 | 1×（正常） |
| 1 | 2× |
| 2 | 4× |
| 3 | 8× |
| 4 | 16× |

> 如果每个地块都种满树，每棵树被 4 棵邻居包围，生长时间 = 2×2×2×2 = **16 倍**

### 最优策略
- 采用**棋盘格交错种植**，确保每棵树都没有相邻的树
- 牺牲一半的土地利用率换取最快的生长速度
